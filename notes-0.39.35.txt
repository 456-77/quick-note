Quick Note 0.39.35（beta 测试版）

本次共 2 项：

1. 新增 Base64 转码弹窗（默认快捷键 Ctrl+Alt+B）
   - 选中一段带 base64 的 URL / 日志直接按快捷键打开，会自动识别并解码显示；
   - 普通文本点「编码」转成 Base64（按 UTF-8，中文/emoji 都正确）；
   - 支持整段 base64、多行粘贴、URL-safe（-_）与缺省 padding；
   - 「结果↑输入」可把编码结果搬回去接着解码，验证往返；
   - 结果可写回笔记（替换原选区 / 插入光标处）或复制。
   （Ctrl+Alt+F 的 JSON 面板里也仍保留 Base64 解码按钮。）

2. Java 实体库支持 Hand 的 @ExtendPOJO 扩展实体
   - 收录 `@ExtendPOJO public class Xxx extends 父类` 时，如果父类已经在实体库里，
     子类代码（连同注解与字段）会追加到父类条目的代码后面，不再单独堆在库末尾；
   - 悬停父类时，卡片里能一起看到扩展子类的字段；悬停子类本身也照常出卡；
   - 解析/迁移时这段代码原样保留，重复收录不会重复插入；父类不在库时按普通新类收录。

桌面安装包与安卓 APK 均已签名构建，可在设置 → 关于/更新 里切换到 beta 通道体验。
