Quick Note 0.39.33（beta 测试版）

本次共 3 项：

1. 分屏文件的「文件内搜索」修复
   全局搜索定位到右侧分屏里打开的文件后，再按 Ctrl+F 会同时弹出原生 Find Bar、
   自绘搜索面板的按钮也不响应。根因是右栏内容装载/切换是异步 setState，搜索查询
   落在了旧文档状态上：高亮与计数对不上、CM 在状态里找不到有效查询就退回默认
   面板。现在定位会等目标文档真正装上再操作，面板命令执行前也会把查询同步进
   当前视图状态；自绘面板不会再触发原生搜索条。

2. 代码块头部：无语言也有复制按钮 + 每块自动换行开关
   - 没有写语言名的裸围栏代码块（``` 后面什么都没有）现在同样有头部条：
     语言位显示「代码」，带复制按钮。
   - 头部新增「自动换行」切换钮（复制按钮左侧），默认跟随设置 → 常规的
     全局开关；点一下只改当前代码块，再点恢复默认。关闭折行时整块按原样单行
     排布、底部出现横向滑杆。

3. JSON / Base64 转换面板支持 base64 自动识别解码
   抓包/日志里的 URL 常把业务标识（甚至整段源码）base64 塞在路径里。现在
   Ctrl+Alt+F 面板新增「Base64 解码」：
   - 选中一段带 base64 的 URL/文本直接打开面板，会自动识别并解码显示结果；
   - 也可以手动粘贴，检测到片段时底部有提示，点按钮解码；
   - 支持整段 base64、多行粘贴、URL-safe（-_）与缺省 padding；
     普通文本/代码/短 ID 不会误判。

桌面安装包与安卓 APK 均已签名构建，可在设置 → 关于/更新 里切换到 beta 通道体验。
