# Quick Note

一款 Windows 桌面 **轻量 Markdown 笔记软件**（附带 Android 版）。目录即仓库，笔记保持
纯 `.md` 文件——可以与 Obsidian、quick-daily-note 插件**共用同一个仓库**，随时换回、
随时同步，不锁数据。

![版本](https://img.shields.io/badge/version-0.32.0-blue)
![平台](https://img.shields.io/badge/platform-Windows%20%7C%20Android-lightgrey)

## 它能做什么

### 写：贴近 Obsidian 的编辑体验

- **实时预览（Live Preview）**：标题、粗体斜体、行内代码、列表、引用、callout、
  `==高亮==`、`$公式$`（KaTeX）、mermaid 图表……边写边渲染；光标所在行显示源码，
  两种模式一键切换（Ctrl+E）
- **表格就是表格**：渲染成真正的表格，**点击单元格直接编辑**、Tab 跳格、
  右键增删行列、按显示宽度对齐管道；Excel/网页里复制的表格粘贴自动转 Markdown
- **成对符号自动闭合**：`*`、`` ` ``、`==`、`$$`……选中文字输入直接包裹，
  代码语境自动禁用
- **粘贴即所得**：截图/文件粘贴自动存进仓库附件目录并插入链接；粘贴纯文本代码
  自动识别语言包成代码块
- **多标签页**：每个标签独立的撤销历史、光标、滚动位置与**阅读进度记忆**
  （读到一半关掉，重开还在原地）
- **分屏编辑**：标签右键「分屏编辑」，把另一篇笔记钉在编辑区右侧**并列编辑**——
  两边都能打字、都有各自的文件内搜索（Ctrl+F），目录面板跟随最后聚焦的窗格

### 找：为「个人知识库」设计的检索

- **全局搜索（Ctrl+K）**：文件名 + 全文内容（表格里的内容也搜得到），同一文件
  多条命中逐行列出、显示行号，支持跨仓库搜索；命中行悬停预览上下文
- **文件内搜索（Ctrl+F）**：浮动卡片、命中计数、大小写/正则/全词/字段联动
  （`user_name` ↔ `userName` 一并匹配）、查找替换
- **大纲目录**：标题层级实时跟随光标高亮，点击跳转
- **标签**：正文 `#标签` 即标签；标签仪表盘聚合管理，新笔记自动打「待整理」
- **速记收件箱**：全局快捷键随时弹出速记（Ctrl+Alt+N），统一进收件箱；
  速记管理视图里按标签筛选、批量归档到任意仓库的任意笔记

### 记：日记、待办与统计

- **日历面板**：按日期建日记（一天可多篇）、ISO 周记、圆点打点、连续记录、
  今日字数（当天全部日记合计，实时更新）
- **模板占位符**：`{{title}}` / `{{date}}` / `{{time}}` / `{{week}}`
- **待办**：按日期分桶、勾选落盘、昨日未完成一键顺延（带来源标记）、
  到点系统通知提醒
- **天气**：新建日记自动查询当天天气插入（免 key）
- **统计**：近 17 周写作热力图、任务完成率、库容量

### 用：为工作流加的「顺手」功能

- **建表语句悬浮（DDL）**：把 `CREATE TABLE` 语句收录进仓库里一篇笔记
  （Ctrl+Alt+L 弹窗粘贴即收），之后光标悬停在正文或表格里的表名上，
  直接浮出该表的建表语句（带 SQL 关键字着色）
- **单词本**：选词快捷收词（Ctrl+Alt+V），弹窗里输入即自动查在线释义
  （音标+中文），查词不必入库；账户级单词本所有仓库共用，支持云同步
- **截图与 OCR**：全局截图快捷键（默认 Ctrl+Alt+G），框选后可直接 OCR 识别
  文字或存进笔记
- **数据文件与预览**：json/sql/yaml 等直接编辑（语法高亮）；pdf / Word /
  PPT / Excel / HTML / 图片点击即预览
- **导出**：导出 PDF（打印对话框或直接落盘文件）、mermaid 图导出 SVG/PNG

### 看：外观与氛围

- **深色高级主题**为默认，浅色/跟随系统可切；Markdown 渲染风格可换
  （默认 / Blue Topaz 风）；自定义 CSS 注入
- **全局背景图**：仓库里选一张图垫在最底层，不透明度/模糊/锐化/亮度/对比度/
  位置/缩放/界面浓度全可调；**壁纸轮换**——选定电脑上任意目录，按分钟定时
  随机或按文件名顺序换图
- 无边框窗口、专注模式（Ctrl+Shift+F）、快捷键全部可重绑（含配置导入导出）

### 同步与多设备

- **云同步**：与 Obsidian 的 daily-sync 服务共用同一个云端仓库——账号密码登录，
  改动后 3 秒自动推送，冲突时界面裁决；**字节精确往返**（换行符、BOM、尾随换行
  原样保留，哈希口径与插件逐条对齐）
- **附件按引用同步**：只上传被笔记引用到的图片，本地缺图按文件名从云端补
- **多窗口多仓库**：最近仓库一键切换，可另起窗口各开各的
- **应用内更新**：启动自动检查，新版本右下角提示一键更新

## 快速上手

1. **安装**：从 [Releases](https://github.com/456-77/quick-note/releases) 下载
   `Quick Note_x64-setup.exe`（或 `.msi`）安装；Android 版下载 `.apk`
2. **打开仓库**：首次启动点击「选择仓库」——可以新建空文件夹，也可以直接指向
   你现有的 Obsidian 仓库，两边互不干扰
3. **开始写**：左侧文件树右键「新建笔记」/「新建日记」，或 `Ctrl+N`
4. **常用的键**：

   | 快捷键 | 作用 |
   | --- | --- |
   | `Ctrl+K` | 全局搜索（文件名 + 全文 + 命令） |
   | `Ctrl+F` | 文件内搜索 |
   | `Ctrl+N` / `Ctrl+Alt+N` | 新建笔记 / 快速速记 |
   | `Ctrl+E` | 实时预览 ↔ 源码 |
   | `Ctrl+S` | 保存（平时自动保存，停止输入 1.2 秒） |
   | `Ctrl+Alt+L` | 收录建表语句（DDL 悬浮库） |
   | `Ctrl+Alt+V` / `Ctrl+Alt+U` | 选中词入单词本 / 弹窗查词 |
   | `Ctrl+Alt+G` | 全局截图 |
   | `Ctrl+,` | 设置（快捷键均可重绑） |

5. **同步**（可选）：设置 → 云同步，填 daily-sync 服务器与账号即可，与
   Obsidian 插件的数据完全互通

> 完整快捷键列表在 **设置 → 快捷键**，全部支持改绑与导入导出。

## 与 Obsidian 的兼容性

- 仓库结构、文件内容完全一致，两边可同时打开同一个仓库（文件监听自动跟上）
- 支持 wiki 语法：`![[图片.png]]`（含 `|宽度`）、`[[笔记]]`、`![[笔记#小节]]` 内容嵌入
- 共用同一份库内配置 `quick-daily-note.json`（日记目录、模板、待办、天气等），
  两边换用不用设置两次
- 云同步协议与 quick-daily-note 插件互通
