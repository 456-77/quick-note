# Quick Note 0.39.4

测试版通道更新（stable 用户不受影响）。修复手机端两处网络收发问题。

## 修复

- **手机上点「立即更新」后系统安装器报「解析错误：解析包时出现问题」**：弱网下
  连接被掐断时，下载循环会「正常」结束、残包被当成完整的安装包拉起安装器（重试
  机制对这类失败完全不起作用）；「复用已下载安装包」路径又只校验文件大小，坏包
  会被原样再次送进安装器。现在下载完成后校验总字节数与 APK 结构（ZIP 头 + 目录
  结尾标记），不完整或损坏的包按失败处理并自动续传重试；复用已下载包前也做同样
  校验，坏包直接清掉重下；半包比服务器文件还长（服务器包换过版本）时清半包重下，
  不再卡在续传报错上。
- **云同步附件下载失败（Peer disconnected）**：蜂窝弱网传大附件容易中途断流，
  此前单发下载一断就废、只能等下一轮同步。现在同一轮内自动退避重试 2 次（共 3
  发）；失败横幅同一文件连续多轮只报一次（成功即复位），不再反复刷屏；附件下载
  的超时从 120 秒放宽到 300 秒（服务端单文件上限 50MB，弱网 200KB/s 约 250 秒
  可达），避免大附件在慢链路上必撞超时。

## 说明

- 服务器上的安装包已人工校验完整（与本地构建哈希一致），问题出在手机端下载链路。
- 若已 downloading 的坏包仍在手机上，本次更新后第一次点「立即更新」会自动清掉重下。
