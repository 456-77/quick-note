# Quick Note 0.39.8（beta 测试版）

本轮为反馈批：十一项桌面体验优化与三个修复，均来自用户手测反馈。

## 表格预览（Excel）

- 筛选条件（chips）增加关闭按钮：点 × 直接清除该列筛选，点条件文字仍可打开编辑面板。
- 筛选条件跨切换保留：切到别的文件再切回来，原来设置的筛选不再被清空（按文件+工作表记忆，清除筛选即删除记忆）。
- 筛选支持多值输入：搜索框用空格/逗号/顿号/分号分隔多个关键词，命中任一即列出——粘一串单号进来回车即可一次筛好；单个关键词行为与之前完全一致。
- 预览文件支持分屏：分屏栏开着且最后聚焦在分屏时，在文件树点击预览类文件（pdf/docx/xlsx 等）直接开到分屏栏；点回左栏同理，跨栏是移动不是复制。

## 日志/文本文件

- 混用换行符的文件（如 CRLF 为主、夹杂 LF 的日志）显示修正：少数派行尾之后的内容按行断开显示，不再挤在上一行行尾；保存仍不改写任何字节。
- 日志被外部程序追加时，正在查看前文的位置不再发生偏移（改为增量采纳，只有贴底时才继续跟随到底部）。

## 文件树与标签栏

- 文件排序规则优化：`-v2`、`(1)` 之类同主名变体排在原文件之后（此前按字典序排在前面）；数字段按数值比较（2 < 10）。
- 左侧面板支持拖拽调节宽度（右缘细条，最小 220px，双击复位，宽度持久化），方便阅读长文件名。
- 左侧面板顶部的上下空隙收紧。
- 激活的标签头自动滚动到标签栏可视区中间（标签多到溢出时切回/新开的标签不再"看不见"）。
- 关闭预览标签页时自动切换到同栏剩余的预览标签（编辑器关标签同语义），不再留下空白区域。
- 选中预览文件时，左侧「定位当前文件」按钮恢复可用（预览文件同样能在树里展开并高亮）。
- 修复：按 Esc 关闭弹窗（快速笔记/收录弹窗等）时，不再连带关闭正在查看的预览标签。

## 语句库（DDL / Java 实体）

- 收录弹窗的「项目 / 标签」输入框支持一次输入多个标签：空格分隔，第一个词为归属项目段落，全部词写入语句的 @tags 行（例：`甲 乙` → 归入甲段落，标签甲+乙）。
- 同名表/类存在于多个项目时，悬浮卡标题行内嵌下拉框直接切换（替代原先标题行下方的项目按钮行）。

## 修复

- 快速笔记弹窗的标签候选下拉在候选较多时每行被压扁、文字只剩上半段——已修复，列表正常滚动。
