# Quick Note 0.39.3

测试版通道更新（stable 用户不受影响）。

## 修复

- **测试版应用内更新报 404**：服务器生成的下载直链丢了端口，桌面端安装测试版必然失败。
  现在客户端用清单地址的来源地址重写下载直链，不再依赖服务端反推。此前因装不上新版，
  一批已修复的问题（如日志文件「不是合法 UTF-8」打不开）会一直留在旧版本上。
- **更新后部分设置被重置**：日记/天气等库内配置文件此前会被云同步当作普通附件整份
  双向同步，任何一台设备上的旧副本都会在下一轮同步里覆盖其他端。现在该配置文件不再
  参与云同步（多端各写各的），同时读取失败期间日记设置改为只读，避免误写覆盖。
  **如果设置已被重置，请在更新后重新设置一次。**
- **表格预览最多只显示 4999 行**：解析上限 5000 行连表头一起计入，数据行只剩 4999。
  上限放大到 20000 行，截断时明确提示「共 X 行，仅预览前 N 行」。
- **表格筛选后按回车等于没筛**：筛选弹窗的搜索框打字后按回车，现在按「搜索匹配 ∩
  已勾选」应用筛选（此前回车只应用勾选集，初始全选时等于原样恢复）。
- **重命名/删除/移动报「拒绝访问 (os error 5)」**：目标被其他程序占用时（比如表格被
  Excel 打开、杀毒软件正在扫描）先自动重试几次，仍失败则明确提示占用原因。
- **重命名弹出的输入框提示「新建」、不预填原名**：新建与重命名此前共用同一行输入且
  状态互不清除，残留的新建状态会让输入行「复活」。现在两者互斥；重命名固定预填
  原名并全选。
- **文件第二行没内容时，添加标签会落到第二行**：现在按「标题/天气/标签」三行约定补
  空行，标签始终落在第 3 行。

## 说明

- 日志文件（.log/.jsonl）的外部追加实时跟随与关闭标签残留，本机已全链路复测通过；
  此前「实时更新不生效」的主因是 0.39.1 对 GBK/UTF-16 编码的日志打开即报错（0.39.2
  已修）加上本版的更新 404 导致新版本装不上。请更新后实测。
- 纯函数断言（标签行落点等）、Rust 单测与 GUI 批测全部通过。
