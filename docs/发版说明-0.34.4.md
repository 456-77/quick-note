# 发版说明 v0.34.4

主题：DDL 悬浮卡大面板化 + 悬浮交互修复、分屏背景图修复。

## DDL 悬浮卡

- **大面板化**：0.34.2 的直接编辑改造后，弹窗缩成了 ~200px 的小窗（文本域固有宽度只有默认 20 列）。现在改为 DataGrip 式宽面板——960px（小屏自适应收窄），体部一大块编辑区，长行不折行、横向滚动；「保存」钮移到标题行右侧（原「编辑」钮的位置），保存结果与错误提示也显示在标题行。
- **移向弹窗不再消失**：此前光标一离开表名（弹窗和单元格之间隔着 6px 定位空隙）弹窗立即收起，永远到不了弹窗。现在移出后有 200ms 宽限，光标落回弹窗或单元格就保持；移入弹窗内部不再收起。
- **弹窗内容可以滚动了**：此前在弹窗内滚动内容会触发全局滚动监听把弹窗藏掉；现在弹窗内部的滚动不再收起（弹窗外的滚动照旧即时收起）。

## 分屏背景图

- 修复「启用分屏后不显示背景图片」：开背景图时右栏自带的一层半透明底与父层的半透明底叠乘后约 96% 不透明，背景图被盖死；现在右栏与左栏一致只吃父层那层，分屏两侧都能透出背景图。

## 维护

- 内存压测脚本（`scripts/mem-stress.mjs`）的临时 xlsx 生成脚本改写到系统临时目录，不再在 `scripts/` 留下临时文件；压测循环加静置读数口径。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
