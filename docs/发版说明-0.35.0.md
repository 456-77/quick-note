# 发版说明 0.35.0

桌面反馈批（2026-10-30 需求单七条）：两个小 bug 修复、一次性能治理，以及语句库的大升级——**DDL 多项目支持 + Java 实体库**。

## 语句库（重点更新）

- **DDL 多项目支持**：同时开发多个项目、表名复用不再打架——
  - 库笔记里用 `## 项目名` 段落归组语句，未分组的语句属「默认」；老笔记不用改，行为与原来完全一致。
  - 收录弹窗（Ctrl+Alt+J）新增**项目输入框**：下拉里是库里已有的项目，也可以直接输入新项目名；留空 = 默认。同名表只在**同项目内**替换，不同项目各存一份。
  - 悬浮弹窗遇到同名表时出现**项目切换 chips**：默认显示**当前笔记标签指定的项目**（笔记里打过 #项目名 标签的会自动匹配），点击可切到其他项目的 DDL。
  - 设置 → 编辑新增**「批量归入项目」**：已经收录了很多 DDL、都是同一个项目的话，填一次项目名点「归组」，现有语句全部归位。
- **Java 实体库**：与 DDL 同一套交互——收录弹窗粘贴 `class / interface / enum / record` 源码自动识别类名（与 CREATE TABLE 混贴也能分别路由），笔记里悬停类名浮出类源码卡（带 Java 语法高亮），`## 项目名` 段落同样区分同名类。库笔记默认 `Java实体.md`（设置 → 编辑 可改路径或留空关闭）。

## 新功能

- **JSON 格式转换面板**（Ctrl+Alt+F，可改绑；命令面板搜「JSON」也有）：打开时自动带入选中的文本——格式化 / 压缩一步到位；**字符串化的 JSON 自动逐层解包**（转了好几层的也能一次还原）；「转为字符串」「还原为 JSON」双向互转，配「结果↑输入」可连续转换；结果可复制或一键写回笔记（替换原选区）。转换只在面板里进行，写回才动笔记。

## 修复

- **表格单元格内按 Ctrl+` 不再复读内容**：选中格子里的部分文字切换行内代码时，会把格子里的其余文字一起复制一份——现在只包住选中的那段。
- **速记换行正常显示**：速记内容里输入的换行一直有存下来，只是列表里没画出来；现在按原样分行显示。

## 性能

- **设置页不再卡顿**：滑杆（背景不透明度/模糊/亮度/搜索上限等）此前每拖一格就重渲整个界面，连拨几下能感觉到明显延迟；现在拖动流畅，落库在后台合并，松手即生效。实测连拨 8 档的阻塞从 311ms 降到 0。

## 其他

- 窗口几何自愈：个别情况下（改窗口大小/最大化的某个瞬间）界面会「上移」——状态栏下方露出一条背景。现在应用会自动检测这种视口错位并复位；若仍遇到，请记一下当时的操作告诉我。
- 全局搜索结果展示上限滑杆、背景图各滑杆手感与此前一致，数值在拖动时即时预览、停手即保存。
