# Quick Note 0.39.7

测试版通道更新（stable 用户不受影响）。

## 修复

- **表格预览的表头行自动识别**：0.39.5 让合并大标题行参与渲染后，「合并大标题
  行 + 字段名行」两行头的表格，筛选列头与值列表用的是第一行（大标题），列头
  也显示成大标题。现在预览会自动识别真正紧挨数据的那一行作为表头行：大标题
  行作为横幅展示在表头上方（不吸附、无筛选钮，随滚动收起），**筛选、列名、
  数据行全部从字段名行开始**。
- 识别规则刻意保守：只有第一行的非空格数明显少于后面几行（不到最满行的一半）
  才判定为横幅结构；普通表格（第一行就是完整表头）行为完全不变，表头较稀疏
  而数据更满的表也不会误判。纯函数断言 8 条（含用户实测文件形状）。

## 说明

- 若遇到识别错误的表格（横幅判定不对），请反馈文件形状，可再补手动指定表头行
  的入口。
