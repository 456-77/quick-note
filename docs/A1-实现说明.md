# A1 实现说明：仓库模型（基础目录 + 多仓库）——前半

> 需求来自用户（2026-10-03）：初始让用户选一个目录作为仓库存放位置，以后建仓库都在
> 这个目录里；配置同步账号后，仓库列表页可见支持同步的仓库，选中开启后自动同步。
> 原方案的「固定私有仓库 + zip 导入导出」废止（见方案文档 §3 修订）。本篇覆盖
> 仓库模型落地与验收；同步联调（登录/推送/拉取）与附件导入属 A1 后半，另行补充。

## 一、模型与决策

### 1.1 基础目录（vault home）

- 用户在引导页选一个**基础目录**（如 `Documents/QuickNote`），其下每个一级子目录
  是一个仓库。仓库文件直接放在用户可见的共享存储里——电脑端拷进来、网盘同步出
  来、Obsidian 用的目录，都能直接打开。
- **技术通道**：`MANAGE_EXTERNAL_STORAGE`（所有文件访问）。 granting 后 app 对
  共享存储拥有原生 `std::fs` 访问权，`vault.rs` 一行不改。SAF 选择器**只用来取
  路径**：把返回的树 URI 换算成真实路径后弃用 SAF，之后零 SAF 交互。
  这是 Syncthing 等应用的标准做法；侧载 APK 无商店审核约束（若将来上 Play，
  再做「无权限→私有目录」的降级路径，本版已支持同款回退）。
- 基础目录存 Rust 侧指针文件（应用配置目录 `vault-home.txt`，与桌面 `data-dir.txt`
  同一模式）：设备级事实不放 localStorage（WebView 清数据不该丢它）。

### 1.2 SAF URI → 真实路径（`saf_uri_to_real_path`）

- 只认系统文件选择器 provider（`com.android.externalstorage.documents`），其他
  DocumentsProvider（第三方网盘）没有 primary 卷语义，明确报错不猜。
- 目录选择器返回完整形态
  `content://…/tree/primary%3AX/document/primary%3AX`——**先截掉 `/document/`
  尾段再解析 tree 段**（单测抓到过这个坑：不截断会把 document 段当路径、因含 `:` 被拒）。
- 只支持主存储卷 `primary:` → `/storage/emulated/0/`；扩展卡/OTG 挂载点因机型而异，
  v1 明确拒绝。

### 1.3 权限以探测为真值（`storage_writable` / `probe_writable`）

「所有文件访问」在系统设置里授予，Rust 侧没有可靠的查询 API——**直接在目标目录
建临时文件再删除**，成功即可写。设置基础目录时探测、引导页授权回来后重查都走它。
模拟器上用 `adb shell appops set <pkg> MANAGE_EXTERNAL_STORAGE allow` 授权，
与系统设置等价。

### 1.4 仓库发现（`list_vaults`）

基础目录一级子目录，深度 ≤3 扫描统计：`.md` 数量、最新修改时间、强仓库特征
（`quick-daily-note.json` / `.obsidian`）。按最近修改排序。点开发走现有
`switchVault` 全链路（含 `activateVault`、同步状态适配），无旁路。

### 1.5 同步徽标语义

同步状态文件（`sync-state.json`）是**单仓库模型**（vault + enabled + 游标/哈希
一体，切仓库由 `adaptStateToVault` 归零并停自动同步——桌面既有安全语义）。因此
列表徽标显示「当前开启同步的那个仓库（至多一个）」：`sync.enabled && sync.vaultName
=== 目录名`。任何仓库都可以在打开后经 设置 → 云同步 开启自动同步，回到列表页
即见徽标。

## 三、验证（模拟器，Android 15 / WebView 124）

单元：`cargo test --lib vault_home` 2 项通过（URI 换算的 tree/document 截断、
非 primary 卷拒绝）；`cargo check` / `tsc` 全绿。

端到端（`node scripts/gui-android-vaulthome.mjs`，全部走真实命令与真实文件系统）：

```
✓ 引导页出现（基础目录未设置）
✓ 基础目录已设置（SAF URI → /storage/emulated/0/Documents/QuickNote，可写探测通过）
✓ 仓库列表发现预置仓库: ["我的笔记"]
✓ 仓库已打开: /storage/emulated/0/Documents/QuickNote/我的笔记
✓ 探针落盘共享存储，行内语法原样（字节精确往返）
VAULTHOME_OK
```

重启补充验证：杀进程重开 → 直接回到上次仓库（home 下校验通过）、不弹引导页、
文件树正确列出共享存储里的笔记。
