# 发版说明 v0.34.7

主题：真机反馈三批修复——复习单词「不认识」停留、背景预览竖屏化、手机端目录选择。

## 单词本

- **复习「不认识」先看释义再走**：点「不认识」后不再直接跳到下一个单词，而是当场翻出这条词的音标、释义与备注并停留（按钮变为「下一个」），看完再推进——正是不认识的词才需要停下来看。「认识」仍然直接进下一个。

## 外观

- **背景预览在手机上改竖屏比例**：此前预览卡沿用 PC 的横向尺寸，竖版壁纸在预览里被压成中间一条，与真实观感完全对不上。移动端预览改为 9:16 竖屏（高度不超过四成屏），预览即所得。
- **「选择目录」在手机上可以直接用了**：此前安卓上所有「选择目录」按钮（壁纸目录、导出目录）点击都没有反应——上游目录选择插件在安卓没有实现目录选择能力。现在手机端换用应用内目录浏览器（底部弹层逐级进文件夹），选定真实路径后照常落盘；桌面端保持原对话框不变。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
