# 发版说明 v0.34.5

主题：DDL 悬浮卡关键字高亮、中文输入法输入不再丢失弹窗。

## DDL 悬浮卡

- **关键字高亮**：编辑区的建表语句现在有着色（关键字/字符串/标识符/数字/注释，与编辑器代码块同一套配色）。实现是「着色层垫底 + 透明字文本域叠在上层」的双层结构——输入法、撤销、选区等编辑行为完全原生，着色层随输入实时重铺、随滚动同步。
- **中文输入法输入不再关闭弹窗**：此前组词/选字时弹窗会被「鼠标移出即收」「滚动即收」等悬浮通道关掉。现在文本域一进编辑态（聚焦或组词中）弹窗就加上编辑锁：
  - 从编辑器悬浮出的弹窗会自动脱离悬浮容器，变成固定浮层（悬浮容器有自己的鼠标生命周期，会连输入一起销毁弹窗）；
  - 编辑态下鼠标移出、滚动页面都不会收起弹窗；
  - 组词进行中连点击外部也不收（候选窗交互可能落到页面上）；
  - 点弹窗外部（非组词中）仍是明确的关闭手势。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
