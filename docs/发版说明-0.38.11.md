# Quick Note v0.38.11

本版本横跨安卓与桌面的多轮反馈修复，重点：vivo 等机型的移动端布局兼容、预览体验全面升级、更新流程可靠性、外观设置增强。

## 移动端布局兼容（vivo 等机型实锤修复）

- **vivo WebView 把触屏媒体特性上报成桌面形态**，导致移动端样式整段失效（应用回落桌面布局）。移动端样式门全部改为 UA 判定的类门，任何 ROM 的 WebView 上都成立；vivo 的启动动画也随此恢复
- 键盘弹出时自动隐藏语句库管理 / 速记管理的页脚元素（不再顶到键盘上方挡内容）
- 语句库管理页上下留白收紧（旧浮动控件避让尺寸废止）

## 预览体验（pdf / word / 图片 / 表格 / html / svg）

- 预览文件与笔记统一标签页形态：底部工具条 [N] 标签页列表可见、可点切换、可单独关闭
- 预览期间药丸/底条常驻；**点击预览内容隐藏药丸，再次点击恢复**
- 预览缩放状态按文件记忆，切走再切回不重置
- PDF 缩放两段式优化：即时视觉反馈 + 停顿后按最终倍率重渲，连续捏合不再卡顿
- mermaid 导出 SVG 改为矢量内联渲染（响应式不发糊）且支持缩放
- 取景框裁剪（自定义适配）：全屏取景、拖动平移、双指缩放，缩放下限保证铺满
- HTML 预览支持双指缩放与拖动平移、点击内容切换药丸
- 预览内滑动不再误触发左右抽屉；打开抽屉自动清除文字选区
- 底部 ‹ › 历史导航覆盖预览文件（笔记与预览间自由跳转）

## 应用内更新（安卓）

- 下载立即显示进度条，页面不再卡住（下载移出 JS 主线程）
- 弱网断点续传：重试从已下载字节继续
- 修复自部署服务器（http）下载被系统明文策略拦截的问题

## 桌面

- 仓库下拉列表支持移除仓库（仅移出列表，文件保留在磁盘）
- 语句库管理面板行首勾选批量操作等此前版本改进持续可用

## 外观设置

- 背景预览按真实屏幕比例等比缩小且叠加界面表面面纱——所见即所得（含可见度）
- 适配方式新增「自定义裁剪」
- 背景设置新增「重置 / 保存」按钮
- 设置滑杆触摸防误触：轻点不改值、纵向滑动滚屏、横向拖动才调值

## 其他

- 文件抽屉动作行新增「目录筛选」（勾选一级目录只显示所选，与桌面同套、按仓库记忆）
- 底部 ☰ 菜单可自定义展示项（候选 13 项，恢复默认一键）
- 图片灯箱：手指抬起后位置偏移修复；操作条避让状态栏、单击切换显隐
- 手动同步与语句库管理入口等稳定性修复
