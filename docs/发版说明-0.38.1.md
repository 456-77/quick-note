# Quick Note v0.38.1 发版说明

2026-11-06 反馈批：语句库管理对齐收件箱、DDL 弹窗点击不再消失、更新弹窗点击必响应，另含测试版通道（beta）与门户免登录。

## 语句库管理（Ctrl+Alt+K）——向收件箱（速记管理）对齐

- **勾选批量栏**：行首勾选框（支持 Shift+点选范围多选），勾选后工具行原位切换成批量栏——**已选择 N 条 · 全选/全不选 · 移动到项目… · 删除 · 取消**，与收件箱同一套交互与观感。
- **批量移动到项目**：点「移动到项目…」后输入目标项目名（或点现有项目 chip）确认，一次落盘（读盘→逐条摘除→统一并入目标段落→写盘），不再逐条等待。**51 条全未分组的库现在一键就能归组**。
- **批量删除**：两步确认（再点一次「确认删除 N 条？」才真删），同样一次落盘。
- 切换「数据表/Java 实体」页签或项目筛选时自动清空勾选，防跨库误操作。

## DDL / 实体悬浮弹窗

- **点击弹窗内任何位置都不再消失**：此前点 ↑/↓ 跳转按钮、保存按钮、项目 chips 时弹窗会被收走（只有点正文文本域能幸免）。现在弹窗内按下鼠标即「落定」为固定浮层并钉死当前尺寸——点击瞬间的形态就是最终形态，点弹窗外面才关闭。
- 此前「点击内容前后弹窗发生变化」的体验也随之消除：弹窗不会再被收掉后重新弹成另一副样子。

## 手机端更新

- **点「下载并安装」必有可见反馈**：此前应用内更新组件不可用或 APK 直链缺失时，点击只尝试跳浏览器、弹窗纹丝不动（浏览器跳转失败时完全静默，误导为「点了没反应」）。现在这类情况弹窗直接显示原因引导（按钮变「重试更新」），同时仍会尝试打开发布页。

## 测试版通道（beta）与门户免登录

- **更新通道设置**：设置里新增「更新通道」开关（稳定版/测试版，默认稳定版）。测试版从同步服务器拉取测试包（检查更新与安装都指向服务端地址），测试包随传随测，稳定通道不受影响。
- **门户免登录**：云同步页「打开云端网页端」先向服务器签发一次性登录票据（2 分钟有效、拼在地址 #fragment 里，不进服务器访问日志），系统浏览器打开即自动登录；失败自动退回普通打开方式。
- 桌面侧新增测试包安装命令（下载→校验→拉起安装器）。
