# Quick Note 0.39.6

测试版通道更新（stable 用户不受影响）。

## 修复

- **手机端更新安装器报「解析错误」的终极防御**：在拉起系统安装器之前，先用系统
  同源的 PackageManager 完整解析下载包，并校验其版本号必须**严格大于**当前版本。
  两道检查任一不过（残包/拼接坏包/旧版本包——部分 ROM 对同版重装也报「解析包时
  出现问题」），都会在应用内清掉坏包自动重新下载，并给出具体中文原因，不再把
  问题丢给系统安装器。此前的 ZIP 头/长度校验保留为快速预检。
- 服务器上的安装包已完整校验（字节、哈希、签名、对齐全部通过）——如本次更新仍
  失败，应用内会显示具体原因，请把提示原文发来。

## 说明

- 经服务器访问日志排查，手机更新期间的下载请求没有到达云端服务器——请顺带核对
  手机端「设置 → 云同步」的服务器地址是否与其他设备一致（桌面端为
  http://120.26.58.22:8080）。
