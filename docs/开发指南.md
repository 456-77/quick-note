# 开发指南（约束、验收与结构）

> 本页自 README 迁入（0.32 整理）。面向贡献者；功能介绍见根目录 README。

## 开发环境

```bash
npm install
npm run tauri dev      # 开发模式
npm run tauri build    # 打包
```

需要 Rust 1.88 及以上（部分依赖要求）、Node 20+；Windows 上还需要 WebView2 运行时
（Win11 内置，Win10 多数已随 Edge 安装）。

## 核心不变量：字节精确往返

同步协议（daily-sync）用内容的 **SHA-256** 判断文件是否变化。因此本项目的硬性约束是：

> 读写链路不得对文件内容做任何隐式改写。换行符、BOM、尾随换行必须原样保留。

一旦编辑器把 CRLF 规范化成 LF、或吞掉 BOM，所有未改动的文件都会被判成"已改动"，
制造大量虚假冲突。为此：

- Rust 侧不做任何内容规范化，只剥离 BOM 并报告其存在，写回时补上；
- 编辑器用 `EditorState.lineSeparator` facet 对齐文件的换行符风格，**序列化必须用
  `state.sliceDoc()`**——`state.doc.toString()` 固定用 `\n` 拼接，会悄悄改写 CRLF 文件；
- 写入前比较内容，一致则不落盘，避免无谓地更新 mtime 触发同步连锁。

### 验收

```bash
./scripts/verify-all.sh    # 逻辑层：磁盘 ↔ 字符串 ↔ 编辑器状态
./scripts/verify-gui.sh    # 界面层：启动真实应用，用 CDP 断言 DOM 并模拟真实输入
```

`verify-all.sh` 一条命令跑完：类型检查 → 重建测试仓库并记录基线 → Rust 集成测试
（字节往返/建删改/配置可选读取）→ 换行符探测真值导出 → 编辑器层往返 → Live Preview
装饰层 → 行内语法边界 → 附件命名链接 → 日记日历纯逻辑（146 项）→ 云同步纯逻辑
（124 项）→ 表格与大纲 → 比对基线确认零改动。DDL 解析、阅读位置、SQL 着色等新增
纯逻辑在 `verify-ddl-progress.mjs` 等脚本里逐项钉住。

`verify-gui.sh` 先以独立 identifier 构建测试变体（WebView2 独立数据目录），再启动应用，
通过远程调试端口读渲染后的 DOM，用真实鼠标键盘完成：打开/编辑/保存 CRLF 完整、
Live Preview 渲染与切换、复选框写回、文件监听（外部改动/冲突）、粘贴附件、文件管理、
额外语法、日记日历（79 项）、云同步端到端（桩后端，40 项）等；结束后还原文件并比对基线。

> 用独立 identifier 有两个原因：测试不再读写日常使用的应用配置；本机有残留实例锁住
> 正式数据目录时测试也能跑。副作用是 `target/release/quick-note.exe` 会变成测试变体——
> 需要正式二进制时重新跑 `npm run tauri build -- --no-bundle`。

**两层测试缺一不可**：装饰层的单元测试能精确断言区间与类名，却测不出 CM6 对插件的
运行时限制（块级装饰、替换换行符——违反会让编辑器整体白屏）；GUI 测试能发现白屏与
事件失效，但定位不到具体原因。两个层面各自抓到过对方的漏网之鱼。

> 测试脚本刻意不复刻换行符探测逻辑。此前的复刻版把 CRLF 误判为 LF，却因为
> LF 分隔符下 `\r` 会作为普通字符留在行内而"通过"——属于假阳性。真值只有 Rust
> 一个来源（`cargo run --example dump-detect`）。

### 内存基线

```bash
powershell -ExecutionPolicy Bypass -File scripts/measure-rss.ps1
powershell -ExecutionPolicy Bypass -File scripts/measure-rss.ps1 -ProcessName Obsidian
```

输出工作集、私有提交、私有工作集三个口径。**三者常给出矛盾结论**：工作集重复计算
Chromium 共享页，私有提交包含已换出到页面文件的部分，跨应用对比建议用**私有工作集**。
已测数据与结论见 [M0-实现说明.md](M0-实现说明.md) 与 [M1-实现说明.md](M1-实现说明.md)。

## 目录结构（核心模块）

```
src/                     前端（React + TypeScript）
  lib/api.ts             Rust 命令的类型化封装
  lib/editor.ts          CodeMirror 6 装配、模式切换、资源上下文 Compartment
  lib/paths.ts           路径与 wiki 目标解析（纯函数，可单测）
  lib/livePreview.ts     Live Preview 装饰层（核心逻辑为纯函数，可单测）
  lib/searchPanel.ts     自绘文件内搜索面板（高亮/计数/替换）
  lib/ddl.ts             建表语句解析/合并/SQL 着色 token（纯函数）
  lib/ddlHover.ts        表名悬浮（编辑器 hoverTooltip + 表格单元格 document 委托）
  lib/bgRotate.ts        壁纸轮换选图（纯函数）
  lib/background.ts      全局背景的 DOM 应用
  lib/settings.ts        本机设置（localStorage + 订阅 + per-vault 背景）
  lib/daily.ts / useDaily.ts / dailyConfig.ts / todos.ts   日记/待办/库内配置
  lib/sync.ts / syncEngine.ts / useSync.ts                 云同步（纯逻辑/编排/界面侧）
  lib/table.ts / tableEdit.ts       GFM 表格解析与编辑命令
  components/SplitPane.tsx          分屏编辑窗格（第二编辑器宿主）
  components/CommandPalette.tsx     全局命令面板
src-tauri/               Rust 侧
  src/vault.rs           仓库文件操作 + 全文搜索 + 同步扫描
  src/watch.rs           文件监听 + asset 白名单
  src/sync_store.rs      本机同步状态的原子存取
scripts/
  verify-all.sh          逻辑层验收（一条命令）
  verify-gui.sh          界面层验收（一条命令，含构建测试变体）
  gui-*.mjs              各主题 GUI 断言脚本
  make-test-vault.sh     生成覆盖各类边界的测试仓库
  measure-rss.ps1        内存测量（三个口径）
docs/                    设计与实现文档（本目录）
```
