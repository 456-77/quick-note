# Quick Note 0.39.5

测试版通道更新（stable 用户不受影响）。

## 修复

- **Excel 预览不渲染合并单元格**：WPS/Excel 里跨列合并的表头（如
  「部分匹配（157 张单 / 205 个节点）」占 F1:M1），预览里只落在其中一个格，
  其余列显示成 (B)(C)(D) 字母占位。现在预览按合并区间铺开（colSpan/rowSpan），
  表头与数据行的纵向合并同样生效；列筛选锚点随合并列头正确定位。
  合并区间按解析窗口裁剪（行/列截断线上的合并收进窗口），纯函数断言 12 条。

## 说明

- 表格第一行如果是「合并的大标题行」，仍会作为表头行展示（下方真正的字段名
  行成为第一行数据）——筛选与列锚点照常可用；若需要自动识别真正的表头行，
  请反馈再议。
