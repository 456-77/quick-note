# 发版说明 v0.34.6

主题：图片预览清晰度、移动端体验批修（输入法/抽屉/手势/返回导航）、DDL 弹窗定位与自动隐藏、单词收录流程简化、安卓图标重做，以及一批桌面/移动通用修复。共 18 项，全部来自 2026-10-27 真机与日常使用反馈。

## 图片与灯箱

- **图片预览清晰度**：预览的缩放从 transform 矩阵变换改为按布局尺寸渲染——浏览器按目标尺寸从原图重新采样，任何倍率下都与原图一致清晰，放大不再发糊。
- **移动端图片查看**：打开时按屏幕宽度适应（超宽截图不再是细长一条）；支持双指捏合缩放、单指拖动平移、双击在「适应宽度 / 原始尺寸」间切换；查看页里滑动不再误触发左右抽屉的开合。

## 移动端

- **新建笔记/日记：输入法「发送」键直接创建**。此前部分输入法（如 vivo）的发送键没有反应，只能靠点「确定」按钮；现在发送键、回车键都能提交，中文组词中确认候选的回车不会被误提交。
- **新建输入行失焦即收**。输入行打开时按输入法的「下一步」跳去别的输入框，输入行会自动收起，不再一直挂在页面上。日历分区的「新建日记」「添加待办」输入框同样适用。
- **键盘弹出时抽屉底部三件自动让位**：在日历面板等抽屉内输入框打字时，分区胶囊、动作行、仓库底行隐藏，输入区直达键盘上缘（0.34.1 只覆盖了抽屉顶部输入行，本版放宽到全部抽屉内输入）。
- **设置二级页按系统返回回到上一级**。在某个设置的分类详情页按系统返回，先回到设置分类列表，再按一次才退出设置——不再直接退出软件。
- **抽屉不再透出背景图**。开背景图时左右抽屉恢复不透明实底（桌面侧栏的半透明是有意设计，保持不变）。
- **新建时自动回到「文件列表」分区**。抽屉上次停留在单词本/日历/收藏等分区时，从主页点「新建笔记/文件夹/日记」会自动把分区与页签带回文件列表，输入行脚下就是文件树。
- **从相册选择壁纸**：设置 → 外观新增「从相册选择」——调起系统相册选一张图，自动把原图拷入当前仓库的附件目录（attachments/background.扩展名）并设为背景，弥补应用暂不支持直接往库里添加图片。
- **应用图标重做（安卓）**：此前安卓桌面图标在圆形/方形遮罩下表现成「白圈 + 小贴片」。现在是规范的自适应双层——深靛蓝渐变全出血底 + 居中发光 Q 图形（缩放进安全区），任意遮罩形状下都完整。

## 通用修复（桌面 + 移动）

- **没打开文件时内容区不可再编辑**：关闭全部标签/切换仓库/删除笔记后回到欢迎页，点击内容区不再出现光标、也不会误改内容（0.33.0 只覆盖了启动首帧，本版补齐了其余四条进入空态的路径）。
- **「定位当前文件」按钮**（IDEA 式）：桌面左栏标题行与移动端抽屉动作行新增按钮，一键在文件树中展开当前笔记所在的最小目录链，滚动到该行并闪烁高亮。高亮只亮这一次（请求 2.5 秒后作废），不会在切换视图时把上一次的目标再闪出来。
- **文件内搜索面板不再遮挡设置与全局搜索**：搜索浮层压到了设置、命令面板之下；移动端位置下移避开浮动按钮。
- **搜索高亮在行内代码上可见**：命中词落在行内代码芯片里时，主题配色的芯片底色不再盖住红色高亮。
- **速记行完整换行**：收件箱管理面板的速记内容不再按两行截断，长文完整展示（面板可滚动）。

## DDL 悬浮卡

- **打开即定位到触发的字段**：点表格单元格浮出的 DDL 面板，滚动位置停在语句中该字段所在行并居中；语句不足一屏时从头展示，不再强制居中，也不会打开就跳到语句底部。
- **切换笔记/切换标签自动隐藏**：DDL 弹窗（含编辑中的浮层）不再残留到别的笔记页面上。

## 单词本

- **收录流程简化**：「＋ 添加新单词」按钮与独立添加输入区移除，搜索框是唯一入口——搜索无结果时点「收录「xx」并查询释义」，在线释义的预览卡直接显示在原位置，保存/取消/手动填写都在原位完成，不再弹出新输入框。

## 命令面板

- **新增「格式化选中的 JSON」**：选中一段压缩的 JSON（排查接口数据常贴的），执行后展开为 2 空格缩进；非法 JSON 会给出原始错误提示。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
