# Quick Note v0.36.0

一轮大更新：**全类型文件同步（M8）** 落地 + 十余条桌面体验反馈修复。2026-11-03 发布。

## 新功能

### 全类型文件同步（M8，需配套 daily-sync 新版后端）

- 同步范围从「正文 + 被引用的图片/PDF」放开为：**范围内的一切文件都同步**——`.md` 仍走正文通道，其余所有文件（任意扩展名、无扩展名、`.json`）统一走附件字节通道，扫描方式从「按笔记引用」改为「按目录扫」。没被任何笔记引用的文件（孤儿附件）也会上云——这正是全类型同步的目的；纯观感文件（背景图等）请用既有的同步排除清单。
- 单文件上限 10MB → **50MB**；每轮下载额度 20 个 / 200MB。首次同步大库时所有文件排队上传、一条一个请求，量大时慢属预期，超限的下一周期自动重试收敛。
- 「笔记引用着、本地却没有」的文件继续按名从云端补下（名字不再限制扩展名）。
- 删除本地文件 → 云端推墓碑 → 其他设备跟着删除；把文件移出同步范围（缩小日记目录）不会误删云端。
- 与旧版客户端兼容：旧版不上传新类型文件，但能正常接收新类型附件的拉取与删除；升级后自动开始全量上传。

### 语句库管理整页化

- 语句库管理（Ctrl+Alt+K）从弹窗改为**速记管理（Inbox）同款整页**：标题行 + 筛选 chips + 平铺列表 + 底部操作，Esc 返回笔记，不再占用标签页外壳。
- 「数据表 / Java 实体」两库**分开看**（筛选 chips 切换，默认数据表），不再混排；搜索只过滤当前库。

### 文件预览标签页化

- PDF / Word / Excel / PPT / HTML / 图片从全屏浮层改为**标签页**：切走后标签保留，点回即看（重进重新渲染，PDF 内存不常驻），Esc 或页内 ✕ 关闭。

### 标签拖拽

- 标签头可**拖动换位**（同栏内拖到某个标签前，悬停显示分界线）；跨栏拖动直接换归属（含右栏最后一个标签移回 = 自动收起分屏）。
- **文件树条目与标签都能直接拖到编辑区左/右半区**：拖到右半 = 在右栏打开（右栏没开就自动开出分屏），拖到左半 = 在左栏打开。右栏开着时按栏接纳，悬停显示整栏虚线描边。
- 右栏标签右键菜单新增「收起分屏（标签全部移回左侧）」；原标签栏上的常驻 ✕ 按钮移除。

### 右键标题复制链接

- 光标在标题行上右键 → 「复制标题链接」：按设置的链接格式生成 `[[笔记#标题]]` 或 `[笔记 › 标题](笔记.md#标题)`。

### txt 文件支持

- `.txt` 加入可编辑清单：进编辑器（纯文本语法）+ 标签页 + 保存 + 同步全链路。

## 修复

- **实时 ↔ 源码切换后位置偏移**：两种视图行高不同导致按像素恢复会漂。现在切换前记视口顶行号，切换后把同一行滚回顶部（分屏两栏各自锚定）。
- **松散列表回车自动空一行续序号**：序号项与上一项之间隔空行时，lang-markdown 会复制「空行 + 新序号」维持松散列表。现在空项回车=退出列表、非空项回车=紧凑续行（序号 +1，任务框给未勾选）。
- **粗体等装饰内的实体不弹 DDL 卡**：着色层不区分大小写、悬浮查库区分——手打大小写与库里不一致时"有下划线却不弹窗"。悬浮查库同口径（先原名、再大小写不敏感）。
- **命令面板选「语句库管理」没反应**：应用级命令被编辑器命令分发器的"无视图即返回"吞掉。语句库 / 收录语句 / 添加单词不再依赖编辑器焦点。
- **分屏右栏最后一个标签「移回左侧」失效**：旧守卫把它禁成死按钮。现在允许移回，右栏空了自动收起（滚动位置留存、脏内容先落盘）。
- **更新面板点了没反应会连点**：检查更新走 GitHub 回退路径时应用内更新直接静默返回。现在点击立即显示「连接中…」并自动重取更新源，拿不到就报错；设置页与更新弹窗按钮在每个瞬态都禁用连点。
- **`[[笔记### 标题]]` 段落跳转不生效**：按直觉写的多 `#` 写法带着前导 `##` 匹配不上标题。现在剥掉小节名前导 `#`（标准 `[[笔记#标题]]` 与宽容写法都支持）。
- **快捷键提示不同步**：顶栏搜索框的 Ctrl K 徽标、空状态主页的键位说明、单词本面板的收词提示改为跟随「设置 → 快捷键」的当前绑定，改绑即时更新。
- 设置 → 关于新增「开源协议 MIT」入口（仓库根已加 LICENSE）。

### 移动端（0.36.0 补两修）

- 左抽屉「标签」分区不再永远显示「还没有标签」：标签索引此前只在桌面侧栏的标签视图触发扫描，移动端抽屉分区没接上；现在分区打开即扫描。
- 键盘弹出时抽屉底部的分区胶囊与仓库栏不再被顶到键盘上方悬浮（输入场景直接隐藏）。

## 升级说明

- 服务端需同步升级 daily-sync（附件通道全类型放开 + 50MB 上限）；先升后端、后升客户端，旧客户端照常工作。
- 桌面安装包（NSIS / MSI）与应用内更新（latest.json 签名）照常；Android APK 见 Release 资产。
