# Quick Note v0.37.2

本版为两项反馈修复。

## 移动端应用内更新

- **修复：点击「下载并安装」后弹窗没有可见变化，像没反应一样。** 下载已在进行时再点按钮，此前会被静默忽略；现在会把弹窗带回下载视图（进度条实时可见）。下载长时间无进展（网络不通或太慢）时会在约半分钟后明确报错并允许重试，不再停在某个百分比上不动。下载进行中「检查更新」也不再打断当前进度显示。

## DDL / 实体库

- **修复：超长的建表语句 / Java 实体类保存时被截断。** 没有以分号收口的完整长语句（从工具里复制出来的建表语句常不带分号）会落在残段兜底上限（此前 4000 字符）被拦腰截断、再原样存回库里，悬浮卡与保存结果都是半条；超长实体类同理（此前 8000 字符）。现在兜底上限提高到远超真实语句的量级，完整语句整条入库。**已经存成半条的语句：重新收录一次（粘贴完整 DDL / 实体类）即可覆盖修复。**
