# 版本演进（开发日志）

> 本页自 README 迁入（0.32 整理）：记录各里程碑与版本的功能落点。
> 更早的逐项变更见 git log 与 GitHub Release 页。

## M0 外壳验证

- Tauri v2 + React 19 + CodeMirror 6 骨架
- Rust 侧仓库操作：列举 `.md`、读取、写入；隐藏路径（`.obsidian` 等）与非 md 文件自动跳过；路径越界拒绝
- 自动保存（停止输入 1.2s）+ `Ctrl/Cmd+S`；内容未变则不触碰文件（mtime 不变）
- 界面显示换行符风格、BOM、字节数、内容 SHA-256，并提供「校验往返」按钮现场验证

## M1 Live Preview

- Live Preview 装饰层：标题、粗体/斜体/删除线、行内代码、链接、复选框（可点击写回源码）、
  列表圆点、分割线、引用、围栏代码块
- 表格渲染成真正的 `<table>`：单元格内的行内语法与列对齐都会解析，点击表格即可切回源码编辑
- Mermaid 流程图等渲染成图，**按需加载**（不进主包）；图定义写错时只显示错误提示
- 图片真实加载（Tauri asset 协议 + 运行时目录授权），相对路径按笔记所在目录解析
- **支持 Obsidian 的 wiki 语法**：`![[图片.png]]`（含 `|宽度` / `|说明` 写法）、
  `[[笔记]]` / `[[笔记|别名]]`；wiki 目标按文件名在全库查找
- **内容嵌入（transclusion）**：`![[某笔记]]` 渲染目标笔记内容，支持 `#小节` 与 `#^块标识`；
  嵌入内容里的原始 HTML 转义（内容可能来自同步，不能当可信 HTML 渲染）
- **额外 Markdown 语法**：裸链接、行内公式 `$...$`（KaTeX）、`==高亮==`、`%%注释%%`、
  `#标签`、callout、setext 标题、手写 HTML（DOMPurify 清洗，只作用于显示）
- **Ctrl/Cmd+点击链接用系统浏览器打开**
- **主题**：浅色 / 深色 / 跟随系统，配色全部走 CSS 变量
- **文件树反映仓库真实结构**（含空目录与非 Markdown 文件；不含笔记的目录默认收起）
- **文件管理**：新建文件夹/笔记/日记、重命名（同步更新 wiki 引用）、删除（移入 `.trash` 可找回）
- **粘贴附件**：自动保存到附件目录并插入链接，重名自动加序号不覆盖
- **文件监听**：外部改动自动跟上；有未保存编辑时弹冲突提示
- 光标所在行显示源码；Live Preview / 源码 双模式切换（Compartment，保留撤销历史）
- 围栏代码块带语法高亮，语言包按需加载

## 多标签页与目录（0.3）

- **多标签页**：每个标签独立的光标、滚动位置与撤销历史，未保存内容切走再切回不丢；
  关闭带改动的标签先落盘；删除/重命名联动
- **左右分栏**：文件树常驻左栏；右侧面板承载 日历/目录 页签，可一键收起
- **目录跟随光标**：实时高亮光标所在标题
- **自定义 CSS**、**待办行对齐插件交互**

## M2 日记与日历

- **按日期建日记**：日期格式与目录可配；同名直接打开绝不覆盖；一天多篇
- **ISO 周记**（跨年不错格）、**模板占位符**
- **日历面板**：打点、双击打开或创建、连续天数、今日字数、「当天日记（N）」列表
- **待办**：按日期分桶、复制与修改文字、墓碑删除、昨日未完成一键顺延
- **与 Obsidian 插件共用 `quick-daily-note.json`**：补丁式写回，插件专有键原样保留

## M3 云同步

- **与 Obsidian 插件共用同一个云端仓库**（daily-sync）：JWT 登录、401 自动续期、
  游标/分页/幂等推送照抄插件
- **哈希口径对齐插件**：已剥 BOM 的正文，CRLF/CR/尾随换行原样参与哈希；磁盘 BOM 保留
- **冲突策略**：本地改动胜出并回推；云端删除本地没动跟删（进 `.trash`）；双边改动列出裁决
- **待办走虚拟文件**：条目级合并、墓碑 30 天、云端回流
- **后台同步**：3 秒防抖推送、每 5 分钟一轮；凭据只在本机
- **附件同步**：按引用扫不按目录扫；本地缺图按文件名从云端补；每轮上传/下载限额
