# 发版说明 v0.34.2

主题：全文搜索按文件聚合（并修「搜索不全」「其他仓库搜不到内容」）、DDL 悬浮卡直接编辑 + 表名变色、更新流程体验重做（进度/后台/防重试）、一批真机报错修复。含两批真机反馈共 9 项。

## 全文搜索（重做）

- **结果按文件聚合**：一个文件只出现一行，右侧显示完整命中数（如「12 处」），摘要取第一条命中（表格行也能露脸）。点击打开笔记并自动预填**文件内搜索**——所有命中在笔记里高亮可跳。
- **修「搜索内容没搜全」**：旧实现在命中条数到达上限后直接停止扫描，文件序靠后的笔记从未被扫过；现在全库必扫，每篇统计完整命中数。
- **修「搜其他仓库只搜到文件名」**：常见字命中会把其他仓库的结果挤出展示上限——现在当前仓库最多占一半展示位，其余让给其他仓库（meta 带仓库名）。
- **修「其他仓库的搜索结果点开只到标题」**：切仓库后等真正切换完成再打开定位，其他仓库的命中同样带出文件内搜索高亮。
- **选中即搜**：编辑器里选中一段文字再打开全局搜索（Ctrl+K），自动带上选中内容作为搜索词。

## DDL 建表语句

- **悬浮卡直接编辑**：悬浮卡现在直接是可编辑文本域，改完点「保存」即写回 DDL 笔记（同名表整段替换、悬浮库即时重载）；Ctrl+Enter 保存。修复了此前点「编辑」按钮弹窗消失的问题（弹窗内点击不再被误隐藏）。
- **表名变色**：笔记里出现已收录的表名（整词匹配）显示主题色+点线下划线，一眼看出哪些表已录入建表语句。

## 软件更新

- **百分比进度**：更新弹窗下载中显示进度条+百分比（安卓下载同步支持）。
- **可关闭后台更新**：下载中可以关闭弹窗，下载在后台继续；桌面端进度按 25%/50%/75%/100% 与失败结果发**系统通知**。
- **防重复下载**：弹窗/设置页双击、重试都不会再叠出多路下载（前端重入闸 + 安卓侧下载互斥）。
- **弱网重试**：安卓下载失败（如「connection abort」）自动重试 3 次，错误提示给出「到发布页下载」的出路。

## 修复

- **点击笔记里的附件链接报错**（`opener|open_path not allowed by ACL`）：补齐桌面权限声明，非 Markdown 附件（html/pdf 等）链接恢复用系统默认程序打开。
- **云端仓库落地位置校验**：落地位置若与已有仓库重叠（选到仓库内部/本身/祖先）会先把一整套云端文件嵌进现有仓库（监听风暴、文件成山、界面卡死）——现在直接拒绝并提示换位置。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
