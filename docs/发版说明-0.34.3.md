# 发版说明 v0.34.3

主题：全局搜索展示可调 + 滚动追加、内存占用优化（xlsx 解析 Worker 化）、批测稳定性加固。

## 全局搜索

- **内容结果展示上限可在设置中调整**（设置 → 通用，默认 60，可调 20–300）。
- **滚到底部自动追加下一批**：不再需要改设置就能看到更多结果；键盘走到列表尾部也会预先扩一页。
- 其他仓库有命中时，首页仍然保证给其他仓库留出一半展示位（0.34.2 行为不变）。

## 内存占用优化

- **xlsx/Excel 预览解析搬进一次性 Worker**：用完即销毁，SheetJS 的模块底数（约 8–15MB）不再常驻主线程——打开过一次 Excel 预览的应用常驻内存直接下降；大表解析有 30 秒超时兜底，加载遮罩不变。
- 复测口径（release exe + 私有工作集，`scripts/mem-stress.mjs`）：空闲约 176MB，低于 0.23 轮基线（~189MB）；连续开关 xlsx/mermaid/大文本无单调上涨（无泄漏）。新增 `scripts/mem-stress.mjs` 供后续回归复测。
- 结论与历史决策一致：JS 堆本身很小（~15MB），大头是 WebView2 底座；挂机/最小化时已有原生级内存回收（SetMemoryUsageTargetLevel，最小化 −30~45MB）。mermaid 的 Worker 化经核实不可行（渲染需要 DOM 做文字测量），可行的隐藏 iframe 方案留待后续版本评估。

## 批测稳定性

- gui-024 应用启动加一次自动重试（消除偶发的「端口通但界面不出」抖动）；gui-035 连接后等应用文档真正就绪再跑断言（消除 localStorage SecurityError 抖动）；滑杆布局断言改为只量当前可见的滑杆行。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
