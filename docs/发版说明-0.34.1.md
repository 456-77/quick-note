# 发版说明 v0.34.1

主题：0.34.0 真机使用反馈集中修复——手势语义重做（内容区横滑）、收件箱整理、输入行自动收起。桌面除「背景图开启时左栏页签底色」外零视觉变化。

## 手势：内容区横滑开抽屉（交互语义变更）

- 双抽屉关闭时，**内容区域右滑打开左抽屉、左滑打开右抽屉**（快速横扫）；抽屉开着时保留「左滑关左抽屉、右滑关右抽屉」。
- 屏幕左右边缘完整留给系统返回手势，应用不再申请边缘手势排除区。
- 防误触：编辑态/键盘弹出时不响应；起手在按钮、输入框、浮动药丸、底部工具条上不响应；已有文本选区时不响应（防拖选择柄误触发）；慢速拖动（>400ms）不算滑动——长按选词不受影响。

## 收件箱（速记管理）

- 打开收件箱时浮动药丸与底部工具条整体让位（面板自带顶栏与快捷键提示，不再被遮挡）。
- 行尾操作区不再常驻占位：行内容占满全宽；编辑 / 添加标签 / 归档（已归档行为撤销归档）收进行尾 ⋯ 菜单，行尾只留常显 ⋯。
- 收件箱内横滑同样可以开合抽屉（右滑左抽屉 / 左滑右抽屉）。

## 输入行

- 新建笔记/日记/文件夹、重命名的输入行：移动端点击输入行以外的任意位置自动取消，不再需要手动关闭。
- 输入行打开期间隐藏抽屉底部动作行/分区卡/仓库行，键盘弹出后空间让给内容。

## 其他修复

- 错误横幅在移动端改为顶部浮出（z 顶层），不再被抽屉/设置/底部 sheet 遮挡。
- 快捷键设置页：修复内容较长滚动时操作按钮行、搜索框与页头相互重叠。
- 设置页：一级/二级页头风格对齐（同高 56px、同分隔线、同关闭钮尺寸）；一级标题去掉「/xx」后缀。
- 单词本：搜索无结果时的「收录」入口提级为主按钮并加引导文案（没有找到？收录「xx」并查询释义）。
- 桌面：开启背景图时，左栏视图页签（知识库/收藏/最近/标签）不再有多余的深色底，与右栏页签观感一致。
- 移动端抽屉：文件列表行距与组件间隙收紧（行高约 46px，仍满足 44dp 触控规范）。

## 升级说明

- 桌面端由内置更新器自动升级（latest.json）；安卓端下载 APK 直接安装覆盖。
- 无数据迁移，配置与仓库向前兼容。
