# 发版说明 0.34.10

真机反馈两处（2026-10-30）。

## 手机端

- **应用内更新流程理顺**：
  - 首次点击「下载并安装」若缺「安装未知应用」授权，会跳系统授权页——此前弹窗纹丝不动、只有一条易错过的底部提示，看起来像「点了没反应」。现在引导文字直接写进弹窗：「需要『安装未知应用』权限：已打开系统设置，请允许后回来再点『下载并安装』」。
  - 下载完成、系统安装器拉起的瞬间，更新弹窗自动关闭——此前三个按钮会重新摆回来，看起来像「更新没生效」。
  - 下载中依旧有整条进度条 + 百分比（下载很快时会一闪而过，属正常）。
- **阅读界面顶部不再压字**：笔记标题此前会被悬浮药丸盖住一截；现在正文起点让开药丸带（滚动后内容照常从药丸下方穿过）。
- **顶部/底部更紧凑**：悬浮药丸贴住状态栏下缘、底条贴近手势条，纵向空间多让给内容。状态栏与手势条两条极窄区域由系统时钟/图标/手势条占用，应用内容不能与其重叠，背景图会铺满这两条。

## 桌面端

- 无变化（仅版本号随版）。

升级方式：安卓端在应用内点「下载并安装」即可（首次需允许「安装未知应用」）；桌面端由内置更新器自动升级。
