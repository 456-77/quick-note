# Quick Note v0.34.0

移动端整体向 Obsidian 看齐的界面重构（含 0.33.1 未单独发版的真机反馈修复）。桌面端零视觉变化。

## 移动端壳层重构（Obsidian 化）

- **无常驻顶栏/底栏**：改为顶部浮动药丸（左=抽屉开关，右=编辑 toggle + ⋮）+ 底部浮动工具条（‹ › 历史、🔍 快速切换与全文搜索、＋ 新建笔记、[N] 标签页、☰ 应用菜单），悬浮于正文之上，沉浸/编辑态自动让位。
- **导航历史**：底栏 ‹ › 按浏览器语义在笔记历史间前进/后退（上限 100 条，切仓库重置）。
- **[N] 标签页切换 sheet**：移动端标签栏隐藏，点徽标弹出全部标签页（分屏徽标/脏标记/固定），点行切换、✕ 关闭。
- **双菜单分工（对齐 Obsidian）**：右上 ⋮ = 当前笔记操作（编辑/切换实时·源码/固定标签页/重命名/收藏/当前笔记标签/关闭标签页/保存）；右下 ☰ = 应用级动作（快速切换与全文搜索/今日日记/速记/添加单词/速记管理/立即同步/右侧面板/设置）。
- **左抽屉分区化（全屏）**：文件列表 / 搜索（名称筛选+全文搜索入口）/ 标签 / 单词本 / 日历 五分区；底部胶囊切换器默认收起、点击展开、选中后收回；新建笔记/文件夹动作行只属于文件列表分区；底部仓库名 + 计数 + 齿轮。
- **仓库切换 radio sheet**：点抽屉底部仓库名弹出全部仓库单选列表，末行「管理仓库…」进仓库主页；当前仓库高亮。
- **手势**：左缘右滑开左抽屉、抽屉内左滑关闭；右缘左滑开右抽屉（大纲/统计）、右滑关闭；sheet/设置等浮层打开时滑动不误触发。
- **沉浸阅读双向切换**：阅读态点正文隐藏全部浮动件，再点一次正文唤回（Obsidian 语义，替代原顶部热区）。
- **仓库主页品牌块**：页顶居中 logo + 名称 + 版本号。
- **一键今日日记**：☰ 菜单「打开/创建今天的日记」走原有命名流程（日期 + 空格 + 名字，同名直接打开不覆盖）。

## 修复（0.33.1 累积）

- **mermaid 图在新版 WebView2（155.0.4283.62）下渲染成空卡片**：页面渲染改为与导出一致的 `htmlLabels: false`（原生 SVG 文本排版），页面与导出物观感完全一致，不再受运行时 foreignObject 回归影响。
- 单词朗读：安卓 WebView 无 speechSynthesis，改走有道 dictvoice 音频（列表行/详情卡/复习卡恒渲染）。
- 系统栏条纹色：edge-to-edge 下原生 windowBackground 与应用表面不一致导致顶/底黑条——qnAndroid.setChromeBackground 桥同步表面色与图标深浅，themes.xml 同步应用色。
- 「显示的是源码，切换编辑模式也没用」：阅读态恒实时渲染（effectiveViewMode），编辑态尊重已选模式。
- 标签弹窗透图：menu-backdrop 补遮罩底色；标签建议改自绘面板（原生 datalist 在安卓渲染透图）。
- 没打开文件时不再可能残留编辑态工具栏；空状态编辑/笔记菜单按钮禁用。
- 仓库路径归一：Rust 侧反斜杠路径与前端正斜杠比对修复（仓库切换高亮/判同）。
