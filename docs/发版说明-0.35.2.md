# 发版说明 0.35.2

移动端体验两连修 + 更新提示脱敏（2026-11-02 反馈）。

## 修复

- **Inbox 顶栏不再互相遮挡**：手机上顶栏一行的宽度装不下「标题 + 副标题 + 搜索框 + 按钮」，副标题「快速整理刚刚记录的内容」被搜索框压住只露半截——现在窄屏下顶栏自动换成两行：标题与副标题一行，搜索框与操作按钮一行。
- **手机上可以打开语句库管理面板了**：底条 ☰ 菜单新增「语句库管理」（速记管理下方）——浏览/搜索已收录的表与类、定位到库笔记、复制语句、删除；与桌面 Ctrl+Alt+K 同一个面板。

## 其他

- **更新提示脱敏**：更新弹窗与 Release 说明里出现的真实笔记名/项目名示例已替换为中性示例（0.35.1 的线上说明也已同步更正）；收录语句弹窗的占位示例换成通用表名。此后的发版说明走自动脱敏词表 + 人工确认双保险。
