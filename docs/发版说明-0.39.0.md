# 0.39.0（测试版）

> 测试版发布：设置 → 通用 → 更新通道 切到「测试版」即可在应用内收到更新；
> 稳定版会在测试通过后另发。

## 语句库管理：整页重做

- 管理页从零复用速记管理（Inbox）的面板形态：页头（统计/搜索/刷新/更多）、
  「数据表 / Java 实体」分段、筛选工具栏、平铺列表、详情抽屉、批量操作栏、
  底部快捷键提示，两端的响应式与触控规则同步对齐。
- 筛选四件套对齐速记：**筛选**（按分组）、**标签**、**日期**、**排序**
  （最新收录 / 最早收录 / 名称），生效条件显示为可移除的 chips。
- 点击语句行打开**详情抽屉**：库路径、分组、收录时间、备注（表级 COMMENT）、
  标签编辑（chips + 新增/移除）、语句全文（SQL / Java 关键字高亮）、定位 /
  复制 / 删除。
- 行上：勾选（Shift 范围多选）、收录时间、分组、标签 chips（点击筛选）、
  表 COMMENT；「标签」按钮 = 行内输入框（Enter 添加 / Esc 取消），「⋯」收
  详情 / 加标签 / 定位 / 复制 / 删除。
- 批量栏：勾选后原位切换，支持「添加标签」（追加语义，不误删已有标签）与
  两步确认删除。

## 语句库数据模型：标签 + 收录时间

- 一条语句可挂**多个标签**（多个项目复用同一份 DDL 不再需要复制两份），
  落盘为语句上方一行 `-- @tags: A, B`（Java 实体用 `// @tags:`）。
- 收录时自动写**收录时间** `-- @time: YYYY-MM-DD HH:mm`；日期筛选与
  「最新收录」排序、列表按 今天 / 昨天 / 更早 分组都基于它。
- **老笔记零迁移**：没有元数据行的语句继续回落到 `## 项目` 段落名（段落名即
  默认标签）；替换旧语句不改它原有的时间与标签；删除语句连同元数据行一起删。
- 悬浮弹窗的项目切换 chips 改为展示标签（多标签用「·」连接），笔记标签的
  默认命中改为「命中任意一个标签」。
- 收录弹窗的项目输入 = 分组（同时作为默认标签），候选包含出现过的标签。

## Excel 预览重做 + 筛选

- 预览从 HTML 注入改为结构化渲染：表头每列一个 ▾，列筛选支持搜索值、
  多选、全选/清空、应用/清除，多列筛选叠加，工具栏显示「共 N 行 · 篩选后
  M 行」与筛选 chips，表头粘性置顶。
- 大表保护：渲染每 600 行分页（显示更多），解析上限 5000 行 × 80 列并提示。
- 新增旧版 `.xls` 支持（之前没有路由，点击无反应）。

## 其他

- 仓库切换菜单每个仓库显示同步状态（同步中 / 未同步），服务器仓库分区标题
  注明「落地到本机后可开启同步」。
- 修复：代码块光标行 / 选中行透出背景图（0.38.7 的修复规则是非法 CSS——
  background 简写的颜色只能出现在最后一层，activeLine 背景实际一直处于失效
  状态，开背景图才暴露）。
- 修复：悬浮卡编辑「## 项目」段落里的语句时报「没有识别到这张表」。
- 响应式：语句库页头窄容器自动换行、副标题省略；详情抽屉加宽。

## 升级说明

- 数据文件变化：收录/设置标签/设置时间后，语句库笔记里会出现 `@tags` /
  `@time` 注释行，属于功能的一部分，请勿整行手删（删掉即回落段落名）。
- 桌面端：应用内更新（测试版通道）或直接下载安装包覆盖安装。
- 安卓端：下载 APK 覆盖安装。
