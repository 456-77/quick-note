# 发版说明 0.35.1

链接编辑体验专项 + 语句库管理面板（2026-11-01 需求单）：三个链接修复、一个新快捷键、一个管理面板。

## 新功能

- **插入内部链接快捷键**（Ctrl+Shift+K，可改绑；命令面板搜「内部链接」、移动端 Markdown 工具栏 🔗 按钮同样可用）：选中文本一键包成 `[[链接]]`——
  - 选中的恰好是库内笔记名（或含 `/` 的路径）→ 直接作链接目标，光标贴在末尾方便继续补全；
  - 其他文本 → 当**别名**：包成 `[[|别名]]`，光标停在前面的目标槽位，直接打笔记名即可——正好是 `[[长笔记名.md|别名]]` 这种「短别名 + 长目标」的书写顺序；
  - 没有选区 → 插入 `[[]]` 光标居中；光标已在链接里再按 = 取消链接（还原显示文字）。
- **语句库管理面板**（Ctrl+Alt+K，可改绑）：DDL 库与 Java 实体库**同一个面板**（与收录弹窗同一套双库复用思路，页签切换）——
  - 按笔记里的 `## 项目名` 段落分组浏览已收录的全部表/类，支持按名称/项目搜索；
  - 每条可**定位**（打开库笔记并跳到那一行）、**复制**完整语句/源码、**删除**（两步确认；删除后悬浮预览、表名着色即时更新，删空的围栏块一并清理）。

## 修复

- **选中链接源码不再翻渲染态**：想选中 `[[...]]` 或 `[文本](url)` 的源码来修改时，一拖选整条链接就翻成渲染态、要改的目标/别名直接消失——现在只要光标或选区落在链接里就保持源码态，编辑全程可见；单击链接文字打开笔记的手感不变。
- **带空格的链接地址能用了**：`[文本](笔记 名字带空格.md)` 这种目标带空格的写法此前按 Markdown 标准解析失败——表现成点不动的半截链接 + 裸露的括号路径；现在整条识别为链接、点击正常打开；`<含 空格.md>` 尖括号写法此前也解析不了，一并修复。
- **行内代码取消不再删内容**（存量 bug）：光标在 `` `code` `` 里按 Ctrl+` 取消行内代码时，代码文字会被一起删掉只剩空格——现在取消只剥反引号、内容原样保留。

## 其他

- 「收录建表语句」更名「收录语句（DDL / 实体）」，快捷键说明同步更新——现在不只收录 DDL，还自动识别收录 Java 实体。
