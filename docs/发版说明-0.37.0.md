# Quick Note v0.37.0

本版为反馈修复批 + 预览/文件列表增强，共 12 项。

## 分屏与拖拽（桌面）

- **修复：拖动标签/文件到编辑区无法开出分屏。** 根因是分屏未开时左栏盖满整个编辑区并吞掉拖拽事件，半区落点永远收不到。现在分屏未开时拖到编辑区右半区直接开出分屏、左半区在左栏打开；分屏开着时整栏接纳语义不变。
- **修复：拖拽提示虚线残留。** 拖拽半途取消（Esc）或松手落在无落点区域时，蓝色虚线高亮现在必定清除，不再需要重启。
- **预览标签可拖动：** 同栏拖动在预览组内换位，拖到另一栏即移过去（拖过去即激活）；右栏可以是纯预览窗格；从文件树把图片 / PDF 拖到左右栏，在对应栏打开预览。收起分屏时右栏预览标签全部移回左栏不丢。

## DDL / 实体悬浮弹窗

- **修复：长语句被截断。** 弹窗体部改为随内容增高（上限约 2/3 屏，超出仍是内部滚动），中短语句不再被硬截一半。
- **修复：点击其他区域弹窗不消失。** 编辑后失焦的浮层现在点弹窗外即收；悬浮到新表名时旧残留卡自动收起，一次只留一张。
- **修复：表格中的表名悬浮卡不切换。** 光标在表格间移动时正常换成当前表的语句 / 移开即消失，旧卡不再钉死。

## 预览

- **修复：资源管理器「打开方式 → Quick Note」打开非 Markdown 文件报预览加载错误。** 启动参数路径统一转为仓库相对路径，json / 图片 / PDF 等类型都能直接预览。
- **修复：预览页与欢迎页重叠。** 只开预览标签时不再透出欢迎空状态。
- **桌面嵌入预览的标题条隐藏**（与标签栏信息重复，省一截空间）；PDF 保留缩放条；手机端标题条保留（标签栏隐藏时的唯一关闭入口）。
- **手机端预览全屏化：** 预览铺满内容区并做状态栏 / 药丸 / 底条避让，不再只占下半屏。

## 文件列表

- **新增「只显示选定目录」：** 右键目录 → 只看此目录，树顶出聚焦芯片（✕ 恢复全部），按仓库记忆。适合大仓库在手机上翻找。
- **修复：手机端标签页顶部「正在扫描仓库标签」反复闪烁。** 扫描只在文件清单变化时重跑，刷新过程静默替换。

## 设置与其他

- **设置页一级 / 二级标题头统一模板**（移动端同高同描边、统一主题色返回键），桌面不变。
- **语句库管理手机端 UI 优化：** 头部避让浮动药丸、底部按钮避让底条、行改两行栅格（表名完整换行不截断）、搜索框独占一行、关闭钮改 ✕。
- **修复：手机选择壁纸目录默认定位到当前仓库根目录**（此前固定从存储根开始）。
