# Quick Note v0.38.0 发版说明

2026-11-05 反馈批：DDL 悬浮弹窗三项升级、语句库管理增强、下拉框统一、开机自启、一批显示与滚动修复。共 12 项。

## DDL / 实体悬浮弹窗

- **表注释（COMMENT）展示**：标题行表名后跟表级 COMMENT（取建表语句末括号后 `COMMENT='…'` 的值，列注释不算），超长省略、悬停看全文。打开表结构一眼看到表的用途。
- **弹窗内容搜索**：标题行右侧新增搜索框，输入即在语句里高亮全部命中并滚动到第一条，Enter/Shift+Enter 在命中间循环跳转，右侧显示「当前/总数」计数。大表找字段不用再肉眼扫。
- **点击弹窗不再变大挪位**：此前悬浮卡点击进入编辑时会脱管放大成大面板（体部 62vh），视觉上「点一下就变了」。现在点击前后弹窗尺寸、位置完全一致——就是悬浮时看到的那张卡，直接可编辑。
- **修复编辑光标与内容行错位**：着色垫底层与透明输入层此前用小数行高（12px×1.55=18.6px），两层逐行累积取整误差，越往下光标偏离越大。两层统一为整数 px 行高，逐行严格对齐。
- **修复单元格多表名弹错卡**：表格单元格里写了两个表名（如 `exp_report_header / exp_report_line`）时，悬浮永远弹第一个的 DDL。现在按光标悬停的那个词取表名（Live Preview 的行内代码 chip 正好一词一 chip），落到哪个词弹哪张卡。

## 表名变色

- **修复代码高亮盖住 DDL 变色**：Blue Topaz 主题下行内代码是橙色（主题规则特异性更高），已收录表名的变色标记被完全盖住。现在两种装饰嵌套方向下 DDL 变色都赢回来——行内代码里的表名也能看到「已收录」的着色与点线。

## 语句库管理（Ctrl+Alt+K）

- **行尾按钮折叠**：每行默认只露「定位 + ⋯」，复制 / 删除收进 ⋯ 展开行，列表更清爽（移动端同步收紧栅格）。
- **移动到项目**：展开行里点目标项目 chip 即把语句移到那个 `## 项目` 段落（定位→删除→合并一次落盘，编辑器缓冲同步替换防自动保存冲掉）。
- **项目筛选**：类似收件箱的筛选 chips 行——「全部 / 未分组 / 各项目」一键过滤，与搜索叠加生效。

## 收录与下拉框

- **收录弹窗 / 快速笔记的下拉框对齐软件风格**：项目框与标签框原来挂原生 datalist（浏览器控件，深色主题里弹出泛白突兀的系统列表）。换成自绘候选列表：输入过滤、↑/↓ 选择、Enter 选中，配色走应用主题变量。Enter 的语义是「补全」——打了半个词按 Enter 补成高亮候选，打了完整的词按 Enter 照原词生效（标签框落原词为 chip，不被最像的候选截胡）。
- **项目默认上一次使用的**：收录成功即记住项目名，下次打开收录弹窗自动预填（收录弹窗与悬浮卡保存共用通道）。

## 单词面板

- **头部去拥挤**：侧栏较窄时「单词本」和「N 个单词」被压到逐字换行（截图实锤）。标题与计数不再换行，计数精简成数字徽标（完整说明挪悬停提示），放不下时整行折行而不是逐字断开。
- 空态快捷键提示本就跟随「设置 → 快捷键」的当前绑定（改绑后提示同步变化），本轮确认无需改动。

## 桌面

- **开机自启**：设置 → 通用 → 打开行为新增开关（桌面专用）。Windows 写当前用户注册表 Run 键，关闭即清除；移动端不显示此项。
- **修复设置页滚轮穿透**：设置面板悬浮在编辑区上方且没有全屏遮罩，光标在面板外/不可滚的左栏时滚轮会滚到底下的笔记。设置开着时面板以外的滚轮一律拦截，面板内部照常滚动。

## 阅读与滚动

- **修复切标签回来内容漂移**：离开再切回标签页时，滚动位置可能被重建中的高度图钳掉、或装饰重建带走几行。切回时与打开笔记同口径做两帧校准，回到离开时的位置。

## 其他

- 语句库管理「删除」通道的编辑器缓冲同步逻辑提取共用，行为不变。
